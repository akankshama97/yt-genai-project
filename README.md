# 🤖 AI Interview Coach
An AI-powered interview preparation platform that helps candidates prepare for job interviews based on job descriptions, resumes, and experience.

## 🚀 Features

- **Personalized Interview Plan:** Generates customized interview preparation roadmaps.
- **Role Compatibility Check:** Evaluates resume and job description to identify skill gaps.
- **Interactive Practice:** Real-time AI-driven technical and behavioral questions.
- **Smart Feedback:** Instant analysis and actionable suggestions to improve answers.

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite, SCSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **AI Integration:** Google Gemini API
